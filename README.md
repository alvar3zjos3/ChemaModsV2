# ChemaModsV2

Menú personalizado para **GTA V Legacy**.

### Créditos

- **YimMenu** → Proyecto original creado por [YimMenu Team](https://github.com/YimMenu)
- **Mr-X-GTA** → Mantenimiento y fork para versión Legacy [](https://github.com/Mr-X-GTA/YimMenu)
- Adaptación y personalización realizada por [@alvar3zjos3](https://github.com/alvar3zjos3)

### Características
- Interfaz moderna y optimizada
- Soporte completo para scripts Lua
- Funciones de jugador, vehículos, mundo y más
- Enfoque en estabilidad para GTA V Legacy (versión 1.72)

### Instalación

1. Descarga la última versión desde la sección [Releases](https://github.com/alvar3zjos3/ChemaModsV2/releases)
2. Usa **Xenos64** como injector (recomendado)
3. Inyecta el archivo `ChemaModsV2.dll` en el juego
4. Presiona **F8** para abrir el menú
