# ChemaModsV2

Menú personalizado para **GTA V Legacy** basado en YimMenu.

### Características
- Interfaz moderna y personalizada
- Soporte completo de scripts Lua
- Optimizado para Legacy (versión 1.72)
- Totalmente privado

### Instalación

1. Descarga la última versión desde [Releases](https://github.com/alvar3zjos3/ChemaModsV2/releases)
2. Usa **Xenos64** como injector
3. Inyecta `ChemaModsV2.dll` en GTA V (preferiblemente en el menú principal)
4. Presiona **F8** para abrir el menú
